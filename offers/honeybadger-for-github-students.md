## 简介

GitHub 学生可免费使用一年 Honeybadger Small：22.5 万错误额度、60 天保留、60 个可用性检查、不限用户和应用。官方写价值超过 $700。

## Description

GitHub students get Honeybadger Small free for one year: a 225,000 error limit, 60-day retention, 60 uptime checks, and unlimited users and apps. Honeybadger lists it as over a $700 value.

## 如何领取

1. 先加入 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」领取一年 Small 方案。
3. 问题可写 support@honeybadger.io。

## How to claim

1. First join the GitHub Student Developer Pack.
2. Go to the "Get it on the official site" button on this page to claim the one-year Small plan.
3. For questions, email support@honeybadger.io.
