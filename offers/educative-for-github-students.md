# Educative GitHub 学生 6 个月

**Educative for GitHub Students**

- 分类 / Category: [学习与科研 / Learning & Research](../docs/categories/learning.md)
- 状态 / Status: Active
- 官网域名 / Domain: educative.io
- 源页面 / Source: [中文](https://edu.52it.de/zh/offer/educative-for-github-students) · [English](https://edu.52it.de/en/offer/educative-for-github-students)

## 简介

GitHub Student Developer Pack 学生可免费使用 Educative 6 个月，在浏览器里做互动课程，无需信用卡。

## Description

GitHub Student Developer Pack members get 6 months of Educative free, with in-browser interactive courses. No credit card is required.

## 如何领取

1. 用学校邮箱的 GitHub 账号通过 Student Developer Pack。
2. 打开本页的「前往官网领取」，在同一浏览器登录 Educative 和 GitHub 后领取。
3. 课程在 My Courses 里。审核可能从 1 小时到数周。

## How to claim

1. Use a GitHub account with your school email to qualify for the Student Developer Pack.
2. Open the "Get it on the official site" button on this page and claim it after logging into both Educative and GitHub in the same browser.
3. Courses are in My Courses. Review can take from 1 hour to several weeks.
