## 📋 领取步骤

1. 用学校邮箱的 GitHub 账号通过 Student Developer Pack。
2. 打开本页的「前往官网领取」，在同一浏览器登录 Educative 和 GitHub 后领取。
3. 课程在 My Courses 里。审核可能从 1 小时到数周。

## 📝 福利简介

GitHub Student Developer Pack 学生可免费使用 Educative 6 个月，在浏览器里做互动课程，无需信用卡。

## Description

GitHub Student Developer Pack members get 6 months of Educative free, with in-browser interactive courses. No credit card is required.
