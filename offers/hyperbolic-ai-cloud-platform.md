## 简介

Hyperbolic 提供模型 API 和 GPU。用教育邮箱注册可获得 $15 额度，可用于模型调用和 GPU 租用。

## Description

Hyperbolic provides model APIs and GPUs. Register with an educational email address to receive a $15 credit, which can be used for model calls and GPU rentals.

## 如何领取

1. 用教育邮箱点击本页的「前往官网领取」注册。
2. 到账 $15 后即可调用模型或租 GPU。额度用完即止，不会按月补充。

## How to claim

1. Use an educational email address to click "Go to Official Website to Claim" on this page and register.
2. Once the $15 credit is applied, you can start using models or renting GPUs. The credit is valid until exhausted and will not be replenished monthly.
