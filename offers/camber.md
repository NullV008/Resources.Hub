## 简介

在读期间免费使用 Camber Student：每月 40 CPU 小时、5 GPU 小时、50 GB 存储和 50 条 Agent 消息。可连接 Postgres、Trino、S3，用自己的数据和代码做 AI Agent，也能从 Cursor 或 Claude Code 经 MCP 运行。

## Description

Free access to Camber Student during your studies: 40 CPU hours, 5 GPU hours, 50 GB of storage, and 50 Agent messages per month. Connect to Postgres, Trino, and S3 to build AI Agents with your own data and code, or run them via MCP from Cursor or Claude Code.
