## 简介

GitHub Student Developer Pack 学生可免费使用 1 个月 Scrimba Pro，含全部课程、项目和编程挑战。

## Description

GitHub Student Developer Pack members get 1 month of Scrimba Pro free, including all courses, projects, and coding challenges.

## 如何领取

1. 先加入 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」领取 1 个月 Pro。
3. 到期后是否续费以 Scrimba 账户为准。

## How to claim

1. First join the GitHub Student Developer Pack.
2. Open the "Get it on the official site" button on this page to claim 1 month of Pro.
3. Whether you renew after expiration depends on your Scrimba account.
