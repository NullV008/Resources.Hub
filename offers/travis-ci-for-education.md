## 简介

GitHub Education 学生可自动获得免费 Travis CI：1 个并发任务，可添加协作者。需遵守合理使用。

## Description

If your GitHub account is in GitHub Education, Travis CI gives you a free account automatically: one concurrent job and as many collaborators as you need. Fair use applies.

## 如何领取

1. 确认 GitHub 账号已加入 GitHub Education。
2. 打开本页的「前往官网领取」，用该 GitHub 账号登录即可自动开通。
3. 学生账户为 1 个并发任务。

## How to claim

1. Make sure your GitHub account is enrolled in GitHub Education.
2. Open the "Get it on the official site" button on this page and log in with that GitHub account to activate it automatically.
3. Student accounts have 1 concurrent job.
