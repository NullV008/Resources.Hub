## 简介

GitHub 学生可免费试用 DeepScan 6 个月，用于 JavaScript 代码质量检查，并和 GitHub 推送集成。每个用户限领一次。

## Description

GitHub students get a free 6-month DeepScan trial for JavaScript code quality, integrated with GitHub pushes. One redemption per user.

## 如何领取

1. 先加入 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」，点 Get the Student Offer。
3. 需用免费方案的团队领取，不能和入门试用叠加。失去 Pack 资格后会降回免费版。

## How to claim

1. Join the GitHub Student Developer Pack first.
2. Open the "Get it on the official site" button on this page and click Get the Student Offer.
3. Must be claimed by a team on the free plan; it cannot be combined with the Intro trial. After losing Pack eligibility, it reverts to the free version.
