GitHub Student Developer Pack 学生可免费使用 Icons8 3 个月，含图标、照片、插画和音乐。

## Description

GitHub Student Developer Pack members get a free 3-month Icons8 subscription covering icons, photos, illustrations, and music.

## 如何领取

1. 先通过 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」领取 3 个月订阅。
3. 时长以 GitHub Education 合作页为准。

## How to claim

1. First get approved for the GitHub Student Developer Pack.
2. Open the "Get it on the official site" button on this page to claim the 3-month subscription.
3. Duration is subject to the GitHub Education partner page.
