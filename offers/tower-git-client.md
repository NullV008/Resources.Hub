## 简介

Tower 是 Mac 和 Windows 上的 Git 客户端。学生申请通过后可以使用 Tower Pro，用来管理仓库和解决冲突。

## Description

Tower is a Git client for Mac and Windows. Students who successfully apply can use Tower Pro to manage repositories and resolve conflicts.

## 如何领取

1. 点击本页的「前往官网领取」，用学校邮箱提交学生申请。
2. 通过后按邮件里的许可证激活。到期日以邮件为准，不要把它当成永久免费。

## How to claim

1. Click "Go to the official website to claim" on this page and submit your student application using your school email.
2. After approval, activate your license using the instructions in the email. The expiration date is as stated in the email; do not assume it is permanently free.
