Tower 是 Mac 和 Windows 上的 Git 客户端。学生申请通过后可以使用 Tower Pro，用来管理仓库和解决冲突。

## Description

Tower is a Git client for Mac and Windows. Students who successfully apply can use Tower Pro to manage repositories and resolve conflicts.
