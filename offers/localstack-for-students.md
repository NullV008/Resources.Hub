## 📋 领取步骤

- 确认 GitHub Education 权益有效。

- 打开本页的「前往官网领取」，用 GitHub 关联并开通学生计划。

- 若进了付费试用，到 Settings → Billing 再选 Student Plan。离开 Pack 后不再符合。

## 📝 福利简介

GitHub Student Developer Pack 学生可在学籍有效期内免费使用 LocalStack 的 AWS 本地模拟器…

## Description

GitHub Student Developer Pack members get LocalStack’s AWS emulator free while they stay in the Pack, including 1,000 CI/CD credits a month.
