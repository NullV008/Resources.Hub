## 简介

GitHub Student Developer Pack 学生可在学籍有效期内免费使用 LocalStack 的 AWS 本地模拟器，并含每月 1,000 CI/CD 额度。

## Description

GitHub Student Developer Pack members get LocalStack's AWS emulator free while they stay in the Pack, including 1,000 CI/CD credits a month.

## 如何领取

1. 确认 GitHub Education 权益有效。
2. 打开本页的「前往官网领取」，用 GitHub 关联并开通学生计划。
3. 若进了付费试用，到 Settings → Billing 再选 Student Plan。离开 Pack 后不再符合。

## How to claim

1. Confirm your GitHub Education benefits are active.
2. Open the "Get it on the official site" button on this page, connect with GitHub, and activate the student plan.
3. If you entered a paid trial, go to Settings → Billing and then select Student Plan. You are no longer eligible after leaving the Pack.
