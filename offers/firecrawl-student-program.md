## 简介

Firecrawl 是 Y Combinator 支持的网页数据提取 API，专为开发者与 AI 应用构建。学生计划为持有有效.edu 或学术邮箱的在校学生免费提供 10,000 个 API 额度，覆盖完整功能：网页抓取（Scrape）、全站爬虫（Crawl）、站点地图（Map）、结构化内容提取（Extract），无限制、无需绑定信用卡，额度到账即用。可用于学术项目、科研、黑客马拉松及个人学习。需更多额度可发邮件至 help@firecrawl.com。

## Description

Firecrawl is a Y Combinator-backed web data extraction API built for developers and AI applications. The student program offers 10,000 free API credits to verified students with a valid.edu or academic email — full access to scrape, crawl, map, and extract with zero restrictions, no credit card required. Credits are added instantly. Eligible use cases include academic projects, research, hackathons, and personal learning. Need more credits? Email help@firecrawl.com.

## 如何领取

1. 使用.edu 或学术邮箱注册 Firecrawl 账号（www.firecrawl.dev）。2. 登录后进入 Settings → Billing。3. 在优惠码输入框填入 STUDENTEDU，点击兑换。4. 10,000 个免费额度立即到账，无需信用卡。

## How to claim

1. Sign up for a Firecrawl account with a.edu or academic email (www.firecrawl.dev).
2. After logging in, go to Settings → Billing.
3. Enter STUDENTEDU in the promo code field and click redeem.
4. 10,000 free credits are added immediately, no credit card required.
