## 简介

学生、教师和高校科研人员可免费使用一年 Sentry 教育账户。官方当前额度：不限成员、5 万错误、5GB 日志、500 万 spans、500 replays、1 个 cron、$20 Seer 点数/月。GitHub Student Pack 也可激活。

## Description

Students, teachers, and university researchers can use a Sentry education account free for one year. The current offer lists unlimited members, 50K errors, 5GB logs, 5M spans, 500 replays, 1 cron monitor, and $20 in Seer credits per month. GitHub Student Developer Pack members can activate it too.

## 如何领取

1. 打开本页的「前往官网领取」。
2. 持有 GitHub Student Developer Pack 时可按页面激活；教师和科研人员按教育资格申请。
3. 当前页面写明免费一年。额度以账户内实际配额为准。

## How to claim

1. Open the "Get it on the official site" button on this page.
2. If you have the GitHub Student Developer Pack, activate it as directed on the page; teachers and researchers apply based on educational eligibility.
3. The current page states free for one year. Allowances are based on the actual quota in your account.
