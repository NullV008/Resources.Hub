## 简介

学生免费领取.stusite.me 域名，无需信用卡，可绑定 GitHub Pages、Vercel 等托管服务。用.edu 邮箱可注册 1 个（有效 90 天），上传在学证明可注册 5 个（有效 1 年）。

## Description

Free.stusite.me domains for students, no credit card needed. Point them at GitHub Pages, Vercel or any host. An.edu email gets 1 domain for 90 days; proof of enrollment gets 5 domains for a year.

## 如何领取

1. 打开 dash.stusite.me 注册账号
2. 用.edu 邮箱验证（Basic：1 个域名，90 天），或上传在学证明（5 个域名，365 天）
3. 选择想要的.stusite.me 域名
4. 在控制面板添加 A 或 CNAME 记录，指向 GitHub Pages、Vercel 等

## How to claim

1. Open dash.stusite.me and register an account
2. Verify with a.edu email (Basic: 1 domain, 90 days), or upload proof of enrollment (5 domains, 365 days)
3. Choose the.stusite.me domain you want
4. In the control panel, add an A or CNAME record pointing to GitHub Pages, Vercel, etc.
