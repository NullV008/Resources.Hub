## 📋 领取步骤

- 用学校邮箱注册 GitHub，并加入 GitHub 学生包，等审核通过。

- 点击本页的「前往官网领取」，用同一个 GitHub 账号登录领取学生账号。以后也从这条学生入口登录。

- 账号一年有效，在读可以续。到期会先暂停，过了宽限期再删，删了数据找不回。
