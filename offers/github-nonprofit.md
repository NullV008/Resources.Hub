## 📋 领取步骤

- 准备慈善登记证明。点击本页的「前往官网领取」，按页面上的联系方式写信给 GitHub Social Impact。

- 说明要免费 Team，还是 Enterprise Cloud 的 75 折。

- 等审核邮件。通过后再在组织账号里升级，不要用个人学生包的入口。
