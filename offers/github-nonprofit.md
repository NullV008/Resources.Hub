# GitHub 非营利组织折扣

**GitHub Nonprofit Discount**

- 分类 / Category: [开发者工具 / Developer Tools](../docs/categories/dev.md)
- 状态 / Status: Active
- 官网域名 / Domain: github.com
- 源页面 / Source: [中文](https://edu.52it.de/zh/offer/github-nonprofit) · [English](https://edu.52it.de/en/offer/github-nonprofit)

## 简介

501(c)(3) 或当地同等资格的非营利组织，可以免费使用 GitHub Team，或在 GitHub Enterprise Cloud 上享受 75 折。这和 GitHub 学生开发者包不是同一项，学生不能拿个人账号申请。

## Description

501(c)(3) or locally equivalent qualified nonprofits can use GitHub Team for free, or enjoy a 25% discount on GitHub Enterprise Cloud. This is a separate program from the GitHub Student Developer Pack, and students cannot apply using their personal accounts.

## 如何领取

1. 准备慈善登记证明。点击本页的「前往官网领取」，按页面上的联系方式写信给 GitHub Social Impact。
2. 说明要免费 Team，还是 Enterprise Cloud 的 75 折。
3. 等审核邮件。通过后再在组织账号里升级，不要用个人学生包的入口。

## How to claim

1. Prepare proof of charitable registration. Click "Go to official website to claim" on this page and contact GitHub Social Impact using the contact information provided.
2. Specify whether you want free Team access or the 25% discount on Enterprise Cloud.
3. Wait for the approval email. After approval, upgrade within your organization's account—do not use the personal Student Developer Pack portal.
