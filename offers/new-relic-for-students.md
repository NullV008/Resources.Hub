## 简介

通过 GitHub Education 验证的学生可免费使用 New Relic。学生账户含每月 500GB 和 3 个完整平台用户。GitHub 教育页写价值约 $300/月。

## Description

Students verified through GitHub Education get New Relic free. The student account includes 500 GB a month and three full platform users. GitHub Education lists it at about a $300 monthly value.

## 如何领取

1. 先注册免费 New Relic 账号，并完成 GitHub Education 学生验证。
2. 在 New Relic 右上角 Help → New Relic for Students → GitHub Education，授权 GitHub。
3. 确认学生身份后才会加上额外数据量和用户数。在读期间有效。

## How to claim

1. First register for a free New Relic account and complete GitHub Education student verification.
2. In the top-right corner of New Relic, go to Help → New Relic for Students → GitHub Education, and authorize GitHub.
3. The extra data volume and number of users are only added after your student status is confirmed. Valid while enrolled.
