## 📋 领取步骤

- 先加入 GitHub 学生包，并登录 Adafruit 账号。

- 点击本页的「前往官网领取」，在账号服务里连接 GitHub，开通 IO+ 和硬件折扣。

- 一年后回到免费档。硬件折扣以当时学生价为准。
