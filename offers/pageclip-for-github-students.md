## 简介

GitHub 学生可免费使用 Pageclip Basic：不限表单数量，含 2 万次提交，适合静态网站表单。在学生资格内有效。

## Description

GitHub students get the Pageclip Basic plan free: unlimited forms and 20,000 submissions, for static-site forms, while they remain students.

## 如何领取

1. 先通过 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」注册领取 Basic。
3. GitHub 教育页写明学生期间免费。

## How to claim

1. First get approved for the GitHub Student Developer Pack.
2. Go to the "Get it on the official site" button on this page and sign up to claim Basic.
3. The GitHub Education page states it is free while you are a student.
