## 📋 领取步骤

1. 点击本页的「前往官网领取」，用个人 GitHub 账号申请。有学校邮箱就先在账号里验证这个邮箱。
2. 学校不发邮箱，或域名认不出来时，上传带日期的学生证、课表、成绩单或在读证明。
3. 通过后再从学生包里逐个打开合作方。每一个都要单独领，不是认证完自动到账。
