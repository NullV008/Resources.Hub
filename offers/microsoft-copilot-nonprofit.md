## 简介

已验证的非营利组织购买 Microsoft 365 Copilot 可少 15%，年付为 25.50 美元/人/月。必须另外已有符合条件的 Microsoft 365 许可证。订阅里包含的 Copilot Chat 不另收费。美国页面还写 Business Premium 员工价为年付 5.50 美元/人/月，约为商业价的 25%。

## Description

Verified nonprofits can save 15% on Microsoft 365 Copilot, at $25.50 per user per month when paid annually. An eligible Microsoft 365 license must already be in place. Copilot Chat included in the subscription is free. The US page also states that the Business Premium employee price is $5.50 per user per month when paid annually, which is about 25% of the commercial price.

## 如何领取

1. 先确认组织已通过微软非营利验证，并且已有 Microsoft 365 许可证。
2. 管理员点击本页的「前往官网领取」，在管理中心按非营利价格购买 Copilot。
3. 付款前核对人数和年付总价。Copilot Chat 已包含在 Microsoft 365 里，不必为聊天单独买 Copilot。

## How to claim

1. First, confirm that your organization has passed Microsoft's nonprofit verification and already has a Microsoft 365 license.
2. Administrators should click "Go to the official website to claim" on this page and purchase Copilot at the nonprofit price in the admin center.
3. Before payment, verify the number of users and the total annual cost. Copilot Chat is already included in Microsoft 365, so there's no need to purchase Copilot separately for chat.
