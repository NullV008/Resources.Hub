## 简介

GitHub Student Developer Pack 学生可领 Blockchair API 密钥：10 万次请求，有效期 1 年，覆盖多条区块链数据。

## Description

GitHub Student Developer Pack members can get a Blockchair API key with 100,000 requests, valid for 1 year, across multiple blockchains.

## 如何领取

1. 先加入 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」，用 GitHub 登录领取密钥。
3. 额度为 10 万次请求、1 年。用完或到期后按普通方案计。

## How to claim

1. Join the GitHub Student Developer Pack first.
2. Open the "Get it on the official site" button on this page and sign in with GitHub to claim your key.
3. The allowance is 100,000 requests for 1 year. After it runs out or expires, regular plan charges apply.
