## 简介

已验证的高校学生可通过 GitHub Education 免费使用一年 Requestly Professional。官方写价值 $270，只限个人账号，每人一次。

## Description

Verified post-secondary students can get Requestly Professional free for one year through GitHub Education. Requestly lists it at $270. Individual accounts only, once per person.

## 如何领取

1. 先通过 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」，用 GitHub 登录领取。
3. 已付费用户会把剩余时间折成额度。一年后不再自动续免费，可买订阅或回到免费版。

## How to claim

1. First, get approved for GitHub Student Developer Pack.
2. Go to the "Get it on the official site" button on this page and sign in with GitHub to claim.
3. Paid users will have their remaining time converted to credit. After one year, it will not auto-renew for free; you can buy a subscription or return to the free version.
