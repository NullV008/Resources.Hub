## 简介

GitHub 学生可免费使用一年 Polypane 个人版，用于多断点网页开发。仅限非商业用途。

## Description

GitHub students get Polypane's individual plan free for one year for non-commercial work. It is a browser for checking sites across breakpoints while you build.

## 如何领取

1. 先通过 GitHub Student Developer Pack。
2. 打开本页的「前往官网领取」领取一年个人版。
3. 官方限定非商业使用。

## How to claim

1. First get approved through the GitHub Student Developer Pack.
2. Open the "Get it on the official site" button on this page to claim one year of the Personal plan.
3. Officially limited to non-commercial use.
