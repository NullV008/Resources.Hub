## 简介

SSH 客户端。持有已激活 GitHub Student Developer Pack 的学生，可免费使用 Termius Pro 和 Team 的全部功能，包括在多台设备间同步，以及和同学共享主机与会话。GitHub 状态必须是 Activated，只显示 Approved 还不行。状态刚变更时，同步到 Termius 最多可能要等 72 小时。

## Description

SSH client. Students with an activated GitHub Student Developer Pack can use all features of Termius Pro and Team for free, including synchronization across multiple devices and sharing hosts and sessions with classmates. Your GitHub status must be Activated; Approved alone is not sufficient. When the status has just changed, it may take up to 72 hours for it to sync with Termius.

## 如何领取

1. 打开 GitHub Student Developer Pack 面板，确认状态是 Activated，而不是刚通过审核的 Approved。
2. 打开 Termius 教育页，用同一个 GitHub 账号绑定。
3. 如果刚刚激活，等最多 72 小时再试。

## How to claim

1. Open the GitHub Student Developer Pack dashboard and confirm that your status is Activated, not just Approved after review.
2. Open the Termius education page and link it using the same GitHub account.
3. If you've just activated your account, wait up to 72 hours before trying again.
