## 简介

GitHub Student Developer Pack 学生可免费使用 RoundPie Lite：最多 3 个任务工具集成、近 6 个月记录。在 Pack 有效期内可续。

## Description

GitHub Student Developer Pack members get RoundPie Lite free: up to 3 task-tool integrations and 6 months of activity history. It can be extended while the Pack membership stays active.

## 如何领取

1. 注册 RoundPie，打开个人资料页。
2. 连接 GitHub Student Developer Pack，升级到免费 Lite。每个 GitHub 学生账号只能升级一个 RoundPie 账号。
3. 不含团队管理和 Jira、Asana 等企业集成。Ultimate 学生另有 5 折，需联系官方。

## How to claim

1. Sign up for RoundPie and open your profile page.
2. Connect GitHub Student Developer Pack and upgrade to free Lite. Each GitHub student account can only upgrade one RoundPie account.
3. Does not include team management and enterprise integrations such as Jira and Asana. Ultimate students get an additional 50% off; contact the official.
