## 简介

通过 GitHub Student Developer Pack 验证的学生，可免费使用一年 Neve Agency（官方写价值 $259），含不限站点、更新和支持。

## Description

Students verified through the GitHub Student Developer Pack get one year of Neve Agency free (listed as a $259 value), including unlimited sites, updates, and support.

## 如何领取

1. 先完成 GitHub Education 学生验证。
2. 打开本页的「前往官网领取」，用 GitHub 登录领取。
3. 许可为一年 Agency，不限站点。

## How to claim

1. Complete GitHub Education student verification first.
2. Open the "Get it on the official site" button on this page and sign in with GitHub to claim.
3. The license is one-year Agency, with unlimited sites.
