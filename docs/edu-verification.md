# 🔎 教育邮箱真伪性查询 / Email Verification

> 查询网站：**[eduverify.net](https://eduverify.net/)**  
> 定位：全球学校邮箱查询系统 · 院校邮箱域名真实性核验

## 这个模块做什么

在购买、领取或使用教育邮箱之前，先用 `eduverify.net` 核验邮箱域名是否对应真实院校，降低遇到假 edu 域名、野鸡学校域名、已停用院校域名或仿冒域名的风险。

**查询入口：** <https://eduverify.net/>

## 使用步骤

1. 打开 <https://eduverify.net/>。
2. 输入完整教育邮箱地址，或输入学校邮箱域名（例如 `xxx.edu`、`xxx.edu.xx`、`xxx.ac.xx`）。
3. 查看系统按「三分类口径」给出的判定结论，并阅读页面上的「判定结论说明」。
4. 对判定结果存疑时，再到学校官网、招生/注册办公室页面或官方邮箱域名页面交叉复核。

## 购买/使用前的核验清单

- [ ] 域名是否能在 `eduverify.net` 匹配到真实院校？
- [ ] 学校官网是否使用同一邮箱域名？
- [ ] 邮箱是否能正常收信、发信、重置密码？
- [ ] 是否有学校门户/SSO，能否看到在读或校友身份？
- [ ] 目标学生优惠的服务商是否明确接受该域名？
- [ ] 学术文件是否真实、合法、属于本人？

## 重要说明

- `eduverify.net` 的查询结果只代表**院校/域名数据匹配情况**，不等于该邮箱一定由学校官方签发。
- 域名真实也不代表一定能通过某项学生优惠；服务商可能还有学籍、地区、年龄、SheerID/UNiDAYS 等额外要求。
- 不要使用伪造的学生证、录取通知、成绩单或在读证明；伪造材料可能违法。
- 本站仅整理公开查询入口与页面说明，不构成对任何查询结果、邮箱商品或服务的背书。
