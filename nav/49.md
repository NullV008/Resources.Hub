## 📋 环境要求 / Requirement

需要国外真实高等教育邮箱，不支持edu.kg等虚假edu域名.

## 🧾 领取步骤 / Claim steps

1. 学校邮箱必须是账号的主邮箱，加在备用邮箱里不算。每个学校邮箱只能领一次，而且只能领一个工作区。
2. 个人教育版只能有你一个成员。如果正在付费，先在网页版的账单里降回免费版。手机 App 里不能升级。
3. 点击本页的「前往网站」领取，用学校邮箱升级。每年都要用这个邮箱再验证一次，验证不了就会退回免费版。把教育版升级成付费 Plus、Business 或 Enterprise 后，这个工作区不能再回到教育版。
4. 已通过 GitHub Education 的，可以另外领取 Education Plus。学生社团要另申请多人版，不走个人教育版。
